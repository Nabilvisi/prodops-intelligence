# PRODOPS Intelligence v2 — Start here for the 13 October 2026 interview

## Open the updated dashboard

1. Open `index.html` in Chrome or Edge. If company/browser policy blocks local files, run `python -m http.server 8080` in this directory and open `http://localhost:8080`.
2. Click **Rokan Reactivation Case** (navigation #03), not Production Analytics, to begin a CV-aligned demonstration.
3. Show **101 wells / 21 candidates / ~13 MMBO** with the correct label: **reported in submitted CV, not independently verified**. Explain the eight DEMO wells are wholly fictional and do not belong to the actual 101.
4. Click **Open illustrative intervention AFE**, explain `quantity x rate`, subtotal, 12% contingency and draft approval gates. Default mock AFE = IDR 1,618.4 million, compared with separate hypothetical WP-004 budget of IDR 1,700 million.
5. Open **Tender & TBE**. Show SOW/TOR clauses, editable weighted technical scoring and the HSE gate (Vendor Gamma fails HSE regardless of technical rating). Export SOW and TBE artifacts.
6. Conclude with **Risk & Reporting**. Distinguish simulation from actual operator decision-making and procurement approvals.
